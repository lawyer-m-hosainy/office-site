# مكتب محمد السيد الحسيني – محامٍ

موقع تعريفي لمكتب محاماة بالمنصورة، مبني باستخدام React 19 و Vite و Tailwind CSS 4.
الصفحات تُولَّد مسبقاً كـ HTML كامل عند البناء (Prerendering) حتى تراها محركات البحث وتطبيقات
التواصل بمحتواها الكامل، ثم يتم تفعيلها في المتصفح (Hydration).

## تعديل المحتوى

كل النصوص في ملفات `JSON` داخل `src/content/` — لا حاجة لتعديل الكود:

| الملف | المحتوى |
| --- | --- |
| `site.json` | بيانات المكتب: الاسم، الهاتف، الواتساب، العنوان، المدينة والمحافظة، الإحداثيات، مواعيد العمل، ونص الأتعاب. |
| `pages.json` | عنوان ووصف كل صفحة كما يظهران في جوجل. **مصدر واحد** تستخدمه الصفحات وسكربت التوليد المسبق معاً. |
| `services.json` | الخدمات القانونية. حقل `icon` يجب أن يكون أحد الأسماء الموجودة في `src/lib/icons.ts`. |
| `articles.json` | المقالات التوعوية. |
| `faq.json` | الأسئلة الشائعة (تظهر في جوجل كأسئلة وأجوبة). |
| `about.json` | نبذة المكتب والرؤية والرسالة وبيانات المحامي. |

### تنسيق نص المقال

داخل حقل `content` يمكن استخدام:

```
## عنوان فرعي
**نص بارز** يكمل الفقرة.
1. عنصر مرقّم
- عنصر بنقطة
```

### إضافة صورة المحامي وبياناته

1. ضع الصورة في `public/` (مثال: `public/lawyer.jpg`).
2. في `about.json` اضبط `"lawyerPhoto": "/lawyer.jpg"` — إذا تُرك فارغاً تظهر أيقونة بديلة.
3. املأ `credentials` ببيانات القيد والمؤهلات، مثال:
   ```json
   "credentials": ["محامٍ بالاستئناف العالي", "عضو نقابة المحامين – الدقهلية", "خبرة 10 سنوات"]
   ```
   القسم لا يظهر أصلاً ما دامت القائمة فارغة.

## الهوية البصرية

في `public/brand/`:
- `logo.svg` — شعار المكتب.
- `og-cover.jpg` — صورة المشاركة (1200×630، يجب أن تبقى أقل من 300 كيلوبايت ليعرضها واتساب).
- `hero-office.jpg` — صورة الغلاف بالصفحة الرئيسية.
- `apple-touch-icon.png` — أيقونة الحفظ على شاشة الهاتف.

## التشغيل والبناء

```bash
npm install
npm run dev        # تشغيل محلي
npm test           # الاختبارات
npm run lint       # فحص الأنواع (TypeScript)
npm run build      # نسخة الإنتاج + توليد الصفحات + خريطة الموقع
```

`npm run build` يقوم بالترتيب بـ:
1. بناء نسخة المتصفح.
2. بناء نسخة التوليد المسبق (`src/entry-server.tsx`).
3. `scripts/prerender.js` — كتابة HTML كامل لكل صفحة، وملف `404.html` منفصل.
4. `scripts/generate-sitemap.js` — خريطة الموقع بتواريخ المقالات الحقيقية.

## النشر على Vercel

المشروع مهيأ في `vercel.json`: بدون إعادة توجيه شاملة (كل صفحة ملف حقيقي)، مع رؤوس تخزين مؤقت
ورؤوس أمان. الروابط الخاطئة تُرجع 404 حقيقية وليس الصفحة الرئيسية.

> عند تغيير الدومين، حدّث `domain` في `site.json` و`Sitemap` في `public/robots.txt`.

## قياس النتائج

Google Analytics مثبت في `index.html`، ويتم تسجيل حدث `generate_lead` عند كل ضغطة على واتساب أو
الهاتف أو البريد أو إرسال نموذج الحجز، مع تحديد مكان الضغطة — لمعرفة أي صفحة تجلب عملاء فعلاً.

## تنبيهات قانونية قبل النشر

1. **سياسة الخصوصية وشروط الاستخدام:** مسودات استرشادية بقانون حماية البيانات الشخصية رقم 151
   لسنة 2020 — **يجب مراجعتها قانونياً قبل الإطلاق.**
2. **محتوى المقالات والأسئلة الشائعة:** معلومات عامة للتوعية، ويجب مراجعتها ومطابقتها لآخر
   التعديلات التشريعية قبل النشر.
3. **قواعد النقابة:** يُرجى مراجعة قواعد النقابة الفرعية بخصوص ما يُنشر من بيانات وإعلانات.
