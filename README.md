# مكتب محمد السيد الحسيني – محامٍ

هذا المشروع هو موقع ويب تعريفي لمكتب محاماة، مبني باستخدام React، Vite، و Tailwind CSS، لضمان السرعة والتجاوب مع جميع الشاشات.

## كيفية تعديل المحتوى

تم فصل جميع النصوص والبيانات في ملفات `JSON` لتسهيل التعديل دون الحاجة للتدخل في الكود البرمجي للمكونات. تجد جميع الملفات في مجلد `src/content/`:

1. **البيانات الأساسية (site.json):**
   - لتعديل اسم المكتب، رقم الواتساب، البريد الإلكتروني، رابط الواتساب، وألوان الموقع.
   - إذا أردت إضافة عنوان المكتب وساعات العمل، قم بتعبئة الحقول المخصصة `address` و `workingHours`.

2. **الخدمات (services.json):**
   - يحتوي على قائمة الخدمات القانونية. لتعديل خدمة أو إضافة خدمة جديدة، قم بإضافة كائن (Object) جديد يحتوي على `id`، `title`، `shortDescription`، `description`، واسم الأيقونة `icon` (من مكتبة Lucide React).

3. **المقالات (articles.json):**
   - يمكنك تعديل المقالات الموجودة أو إضافة مقالات جديدة لتوعية العملاء. تأكد من إضافة `id` فريد لكل مقال.

4. **من نحن (about.json):**
   - تعديل نبذة المكتب، الرؤية، الرسالة، والقيم.
   - بالإضافة إلى مساحة لبيانات المحامي الأساسية (الاسم، اللقب، النبذة).

## الهوية البصرية والصور

الملفات البصرية مخصصة في مجلد `public/brand/`:
- `logo.svg`: ضع شعار المكتب هنا بصيغة SVG.
- `favicon.svg`: أيقونة المتصفح.
- `og-cover.jpg`: صورة الغلاف التي تظهر عند مشاركة الرابط على منصات التواصل الاجتماعي.
- لرفع صورة شخصية للمحامي، أضف ملفاً باسم `lawyer.jpg` في مجلد `public/` وقم بربطه في صفحة "من نحن".

## تنبيهات قانونية هامة قبل النشر

1. **سياسة الخصوصية:**
   - تم إنشاء سياسة خصوصية أولية توافق قانون حماية البيانات الشخصية المصري (رقم 151 لسنة 2020). **يجب مراجعة سياسة الخصوصية وشروط الاستخدام من قبلكم قانونياً قبل إطلاق الموقع رسمياً.**

2. **قواعد النقابة:**
   - يرجى مراجعة قواعد النقابة الفرعية المختصة للتأكد من توافق إطلاق الموقع والبيانات المنشورة مع اللوائح المنظمة لمهنة المحاماة قبل الإطلاق وإخطارها إن لزم الأمر.

## تشغيل الموقع محلياً

لتشغيل الموقع على جهازك للتطوير:
```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج (Build):
```bash
npm run build
```
